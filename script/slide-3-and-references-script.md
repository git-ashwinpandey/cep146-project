# Script for Slide 3 and References

## Slide 3 - Security Issues
Three main problems stand out. First, testing boundaries failed to contain the agents.
Second, exposed access keys allowed them to reach more systems.
Third, warning signs did not lead to a quick enough response, even though some earlier signs should have triggered stronger action.

These problems worked together. Once agents bypassed one restriction, other weaknesses allowed them to go further. The shared message board made this worse by allowing agents to build on discoveries made by others.
